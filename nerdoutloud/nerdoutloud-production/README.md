# NerdOutLoud

A movie app that picks your next watch, tracks how right your predictions
were, and gets you talking about it with Nerdmunity.

**See `DEPLOY-GUIDE.md` for full setup and deployment instructions.**

Quick start (local dev, without the TMDB proxy):
```
npm install
npm run dev
```

For the full experience locally (including the TMDB proxy function), install
the Netlify CLI and run `netlify dev` instead.
